# Tools & Plugins

* * *

## Summary

The following is intended to provide an overview of the core tools and plugins used for building WordPress websites. Some plugins will be used for all site and some may before specific pieces of functionality. It should be considered a general aim that websites use as similar functionality as possible and an alternative plugin should only be used after review and discussion to ensure that there is good reason.

## Core Plugins

The following plugins should be installed as standard:

|     |     |
| --- | --- |
| **Plugin Name** | **Description** |
| Beaver Builder | A drag and drop website builder that allows non-technical users to easily manage basic content. |
| Beaver Themer | An extension to Beaver Builder that allows the building of “_theme parts_”, i.e. header, footer, single templates and archives using Beaver Builder. |
| Toolset Types | A plugin that allows the easy adding of Custom Post Types (CPTs), custom / meta fields and taxonomies. |
| Toolset Views | A plugin that allows the creation and editing _Content Templates, Views_ and _Archives_ using HTML, CSS and JavaScript. These items can then easily be embedded anywhere in the site as well as be nested within each other. _Content Templates_ can be used for small static or dynamic elements or as a part of _Views_ or _Archives_. |
| Toolset Forms | A plugin that allows the creation of forms for both new and existing content on the front end of a WordPress site. In the simplest terms this could be a contact form, more complicated cases could include user submitted content. |
| BDVS Beaver Themer | A custom plugin that creates a link between Toolset Views and Beaver Builder; _Content Templates_ and _Views_ can be created using the Toolset interfaces and easily embedded in a Beaver Builder page using the _BDVS Content Template_ Beaver Builder module.<br><br>Tags can be added to the Toolset elements allowing templates to be populated dynamically either by user / admin edited content in Beaver Builder, or with data direct from the database using Beaver Themer field links within Beaver Builder.<br><br>The plugin also adds a number of utility functions and shortcodes to make various tasks simpler. |

## Supporting / Commonly Used Plugins

|     |     |
| --- | --- |
| **Plugin Name** | **Description** |
| [301 Redirects](https://en-gb.wordpress.org/plugins/eps-301-redirects/) | Redirects plugin for managing and URL redirects as needed. |
| Be Devious and Slick | A custom plugin that does little more than enqueuing the JavaScript and CSS for the [Slick Slider](https://kenwheeler.github.io/slick/) plugin. |
| Beehive Pro | A WPMU Dev plugin for adding and managing Google Analytics. |
| [Better Search Replace](https://en-gb.wordpress.org/plugins/better-search-replace/) | A small plugin that allows searching and replacing text strings within the database from the admin area. Generally used when changing a site from it’s development domain to it’s live domain. |
| [Easy WP SMTP](https://en-gb.wordpress.org/plugins/easy-wp-smtp/) | Allows the sending of transactional emails (password resets, form submissions etc.) via a 3rd party SMTP service for better deliverability. |
| PowerPack for Beaver Builder | An add-on that provides additional modules for Beaver Builder. Since most are more advanced layouts but less flexible that BDVS Beaver Themer, this is not used unless a requirement is very specifically met by one of it’s modules. |
| [Simple Page Ordering](https://en-gb.wordpress.org/plugins/simple-page-ordering/) | Allow drag and drop ordering of hierarchal posy types, used when administrators need to be able to order content and CPTs by arbitrary criteria. |
| Smush Pro | A WPMU Dev plugin for processing images. |
| [Stop Emails](https://en-gb.wordpress.org/plugins/stop-emails/) | A very simple plugin that will block all outgoing emails from a site if needed. Often if you need to ensure that emails are not sent to website end users in error. |
| WP All Import / Export Pro | A set of plugins used for importing and exporting data, covers various scenarios, e.g. migrating blog posts or other content, reporting, setting initial development content on a site. The import plugin can also be used to pull and sync data from 3rd party APIs and feeds. |
| [WP Mail Logging](https://en-gb.wordpress.org/plugins/easy-wp-smtp/) | Log all outgoing emails from a website, generally useful for tracking and debugging. |
| WPMU DEV Dashboard | Allows easy installation of WPMU Dev plugins. |
| [Yoast Duplicate Post](https://en-gb.wordpress.org/plugins/duplicate-post/) | Useful for duplicating content, often when adding dummy content to a site during development if needed. |
| [Yoast SEO](https://en-gb.wordpress.org/plugins/wordpress-seo/) | The go to for SEO. |
